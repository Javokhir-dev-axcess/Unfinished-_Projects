This is a simple Python voice assistant project I built with tutorial videos and Google Gemini API. I followed video guides to learn how it works and put the code together. It listens to voice commands, understand what the user say, and reply back with helpful answers or do simple tasks on the computer.

Features
- Voice input and speech recognition from microphone
- Smart AI responses powered by Google Gemini
- Text-to-speech output so the assistant can talk back
- Basic desktop helper commands and quick answers
- Built while learning from tutorial videos, easy to customize later

Project Files
- jarvis.py — main Python script that run the voice assistant loop and connect to Gemini.

How to Run
1. Install the required Python libraries for audio, speech recognition, and Google Gemini.
2. Add your own Gemini API key in the code or environment variable.
3. Run python3 jarvis.py and start speaking to Jarvis.

This project only tested in Linux, i tested in Linux Mint terminal. For  Windows 10/11, it requires extra packages.
